# Oykumto Coffee ☕

This is a website I built for a made-up cafe while teaching myself web development.

It's written in plain HTML, CSS and JavaScript, with no frameworks. I wanted to understand how everything works from the ground up.

**Live site:** https://oykumto-source.github.io/cafe-web/

## What's in it

- A home page with the cafe's story, house favourites, opening hours and a newsletter sign-up
- A menu page with tabs for coffee, tea, bakery and brunch
- A layout that works on phones too, with a collapsing menu

## What I learned

How HTML, CSS and JS fit together, Flexbox and Grid, making a site responsive, CSS variables, and handling clicks with JavaScript. Also that a single missing `*/` can break half your page.
